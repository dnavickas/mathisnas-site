# mathisnas.com

The website of Mathisnas, the free math practice app (an IT Tech app): a short app page, the privacy
statement and the terms of use, in English (`/`) and Lithuanian (`/lt/`). The app's code is in a
separate private repo; its spec (section 17) describes this site.

- Plain static HTML and CSS, served by GitHub Pages from the `main` branch (`CNAME` = `mathisnas.com`).
- No cookies, analytics or scripts, and nothing loaded from other sites: the fonts (Red Hat Display,
  Poppins; SIL Open Font License, texts in `assets/fonts/`) and icons are served from here.
- Colours, icon and mark come from the Mathisnas brand (IT Tech design workspace). Headings are uppercase.
- The English and Lithuanian pages say the same thing, and the same as the app's About screen.
  When a legal text changes, change both languages and the "Last updated" date.
- The app name "Mathisnas" is never declined in Lithuanian; use "programėlė" in the needed case.
